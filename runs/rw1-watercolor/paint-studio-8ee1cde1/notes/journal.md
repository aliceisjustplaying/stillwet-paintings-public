  Practical lessons (hypotheses, observed on cold-press seed 4127):
  - b:wash refills the brush along every row, so a full-width wash lays full-strength cover everywhere. Overlapping wash calls stack. Glazes need <=0.02 units per 4µL to stay light (0.02 raw-sienna + traces over 1140x160 gave a gentle warm shift).
  - buff-titanium at >=0.3 units per 2µL turns any mix opaque and pale. Over darks it makes chalky pills. Leave it out of darkening glazes.
  - Loads add to what the brush already holds, so use a fresh brush name per graded row.
  - A drop's halo reaches 1.8r, so drops pull wash pigment far beyond the intended edge.
  - Wall-time limit: about 400 brush strokes per chunk is safe; a chunk of about 560 strokes timed out (12 min), and so did a loop with a bad exit condition.
  - Forest: broken dabs (width 5-14, 0.4+0.07w µL, 0.04s) read as trees. Long paired lit/shadow curves read as terraces. Glaze rows over dabs unify them (hookers/sap .18 each, pg .03, 2µL, width 16, rows 8 apart over clean-water rows).
  - Mist veil that worked: buff1.5/cer.1/ultra.1/rose.02/pg.02 ×f, 2.2µL, width 22, rows 8 apart laid over 2µL clean-water rows, f graded.
  - Cumulus lifts: small spiral lifts (width 16, 1µL, 0.08s) into a wash 0.6-2.5s old.
